# CoderPlan API Collection

CoderPlan is a unified LLM API gateway with OpenAI-compatible protocol. Access Claude, GPT, Gemini, DeepSeek, and Grok through a single API endpoint at ~0.7x official pricing.

## Authentication
- **Type:** Bearer Token
- **Header:** `Authorization: Bearer {{CODERPLAN_API_KEY}}`

## Documentation
- **API Docs:** https://docs.coderplan.ai
- **Website:** https://coderplan.ai
- **Pricing:** Pay-per-use, ~0.7x official pricing

## Getting Started
1. Sign up at https://coderplan.ai and get your API key
2. Set `CODERPLAN_API_KEY` variable
3. Test with "List Models" request first
